# 🛒 Retail Sales Data Cleaning & Visualization

## 📌 Project Overview

This project focuses on cleaning, processing, analyzing, and visualizing a real-world retail sales dataset.

The project uses the **Superstore Dataset** from Kaggle. Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn are used for data preprocessing and visualization.

The main goal is to understand the data, handle data-quality problems, discover useful business insights, and present the findings through visualizations.

---

## 🎯 Objectives

The objectives of this project are:

- Load and understand a raw retail dataset
- Identify missing values
- Handle missing values
- Detect and remove duplicate records
- Convert incorrect data types
- Detect and handle outliers
- Perform exploratory data analysis
- Analyze sales and profit
- Create meaningful visualizations
- Identify important business insights
- Save the cleaned dataset
